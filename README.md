### About Me

I build products end-to-end — from database schema to mobile UI. I started with small scripts and grew into architecting systems used by real people. Most of my work lives at the intersection of backend logic and product thinking.

Based in **Almaty, Kazakhstan**, currently deep into **OinGo** — a platform I'm building for computer clubs across Kazakhstan.

---

### Projects

#### OinGo — Platform for Computer Clubs

I started OinGo because existing solutions for gaming clubs in Kazakhstan were either nonexistent or terrible. I built the whole platform: a mobile app where players can find clubs, book seats, pay via Kaspi, order food from their PC and hang out with friends.

On the other side, club owners get a web dashboard to manage their hall in real time — including the PC map, pricing, kitchen orders, analytics and remote device control.

**Mobile** · Expo SDK 54 · React Native 0.81 · TypeScript · TanStack Query · NativeWind · i18next · WebSocket  
**Admin Panel** · Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Recharts · Radix UI  
**Backend** · Django 6 · Django REST Framework · PostgreSQL · Redis · Django Channels · WebSocket · Firebase · Supabase

[oingo.kz](https://oingo.kz/) · KZT · Kaspi integration

#### INO Center — Portal for IITU's Innovation Center

A public-facing portal for the innovation center at my university. I built it so the team could manage courses, news, applications and team profiles directly from the admin panel without touching the frontend.

The portal supports three languages out of the box.

**Frontend** · React 19 · React Router 7 · Vite 7 · Axios · i18n (RU / KK / EN)  
**Backend** · Django 6 · Django REST Framework · PostgreSQL · django-modeltranslation

[ino.iitu.kz](https://ino.iitu.kz/)
